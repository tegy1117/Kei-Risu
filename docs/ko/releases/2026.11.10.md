# Kei-Risu v2026.11.10

PocketRisu v1.17.0 (`40851fc9831856a36cb5c14799c1f501f32dc133`)까지 통합했습니다. 기반 v1.14.0 이후 111개 커밋의 계정 가져오기, Proton Drive 가져오기, 플러그인 V3 안정성, 저장/세션 수정, 토크나이저와 모델 레지스트리 개선을 포함합니다.

## 업데이트

- RisuAI 계정에서 가져오기: risuai.xyz 계정에 저장한 캐릭터, 채팅, 설정, 이미지를 서버가 직접 받아 교체합니다. 중단 후 재시작, 재로그인 이어받기를 지원하며 인레이 이미지는 가져오지 않습니다.
- Proton Drive 공유 링크로 캐릭터, 모듈, 프리셋, 플러그인을 바로 가져옵니다.
- RisuAI 약관 동의 게이트: RisuRealm, MCP OAuth 로그인, 계정 가져오기 사용 시 최신 약관 동의를 요구합니다. 이전 동의는 기기별로 승계되지 않습니다.
- RisuRealm 제작자 차단, 플러그인을 통한 플러그인 설치 확인창 개선.
- Lua 폼 트리거(`risu-form`, `onFormSubmit`), `generateImage` 이미지 방향, `axLLM` 보조 모델 모드, 트리거 팝업 자동완성.
- 모델 프로필 22종 추가: GPT-6.1 Sol, Gemini 4 Argon, Claude Sonnet 5.5/Haiku 5.5, OpenRouter/LLMGateway/Vercel/NanoGPT 변형 등.
- 토큰 카운트 어휘 수정: Llama3는 llama3 vocab, Gemini/Gemma는 Gemma3 262k vocab을 사용합니다. 대부분의 토큰 수가 줄어 같은 최대 컨텍스트에 더 많은 기록이 실리며, `strongBan` 캐시는 새 키로 다시 계산됩니다.
- 플러그인 V3 안정성: 권한을 플러그인 코드에 바인딩해 코드가 바뀌면 다시 질문하고, unload/terminate 시 남은 요청을 정리하며, `getItem`의 `0`/`false`/빈 문자열 처리와 SafeElement 이벤트 격리를 수정했습니다.
- 원본 RisuAI 플러그인 저장 구조 복원(1회성), 손상 gzip 방어, 업스트림 SaveKV 블록 경고 후 skip.
- 저장/세션: 서버 재시작 직후 저장한 채팅이 사라지던 문제, 다른 기기 탭 때문에 세션이 반복 비활성화되던 문제, 백업 업로드 stall, 빈 캐릭터 폴더 유지.
- 번역기 언어가 비활성인데 번역이 실행되던 문제, HypaV3 청크 재임베딩, 정규식 로어북이 처음으로 동작하던 문제, iOS Safari 입력창이 위로 튀던 문제 수정.
- 빌드 도구: vite 8.3.4(Termux ARMv8.0 SIGILL 수정), Proton 가져오기 의존성과 패치 추가.

## Kei-Risu 기능 보존 및 신규 변경

- 동시 채팅과 API 키 요청 슬롯: 채팅별 생성 상태를 유지하고, API 키/제공자별 동시 요청 제한과 FIFO 공유 큐를 적용합니다. 중지와 정리는 해당 실행 범위에만 적용됩니다.
- 서버 기반 임시 사이드챗: 브라우저나 패널을 닫아도 서버에서 생성이 계속되고, 정식 채팅으로 승격할 때 메시지 ID를 재발급하며 모델/프롬프트/Agent 바인딩을 유지합니다.
- Agent 프리셋 구성 정리와 상속 메인 프롬프트 안내 명확화, 사이드챗을 컴포저 메뉴로 이동.
- 로어북 상태 보존 수정: 생성 중 로어북 상태가 다른 채팅이나 이후 요청에 오염되지 않습니다.
- 모바일 클립보드 이미지 붙여넣기: paste/beforeinput과 전용 버튼으로 이미지를 첨부하고, 채팅 전환 시 오래된 업로드를 차단합니다.
- PDF 프롬프트 변환: 프리셋별 off/standard/quality/max 모드와 최근 텍스트 비율을 지원하고, 어댑터별로 PDF 문서 파트를 생성합니다. 이미지, 도구 호출, 추론 서명은 원형을 유지합니다.
- 다음 기능은 그대로 유지됩니다: Agent 사전/사후 파이프라인, MCP/도구 네트워크/관리형 Tool App, 함수별 도구 노출과 정규식 단계, 주사위/선택 도구, 모델 프리셋/바인딩, 캐릭터 비활성화, PocketRisu 양방향 마이그레이션, 요청 로그/상태 UI, 자체 업데이트 보안, Kei-Risu 브랜딩/업데이트 경로, 기존 저장 볼륨 이름.

## 검증 및 호환성 참고

- 검증: 타입 검사 오류 0개(기존 접근성 경고 4개), 프런트엔드 및 사이드챗 런타임 빌드, 도움말 키 검사 통과.
- 클라이언트 1,841개 통과(3개 제외), 서버 262개 통과, 호환성 155개 통과(6개 제외: 업스트림 백업 fixture를 요구하는 5개와 실제 RisuAI 계정을 요구하는 1개).
- 서버 실행 의존성 매니페스트가 실제 요구사항과 일치함을 확인했습니다.
- 저장/DB 스키마 버전은 올라가지 않았습니다(`appVer` 2026.2.291 유지). 기존 볼륨 `risuai-nodeonly_risuai-save` 이름과 데이터를 그대로 사용합니다.
- 롤백 주의: 플러그인 로컬 저장소의 바이너리 값이 새 포맷(PLS/1)으로 저장됩니다. 이번 버전에서 새로 저장한 바이너리 값은 이전 버전으로 되돌리면 읽을 수 없으므로, 롤백 시 업데이트 전 save 백업도 함께 복원해야 합니다.
- 정규식 로어북이 처음으로 실제 동작하므로 기존 데이터에서 로어북이 갑자기 활성화될 수 있습니다.
- RisuAI 약관 동의 UI가 새로 표시될 수 있고, 코드가 바뀐 V3 플러그인은 권한을 다시 질문합니다.
- HypaV3는 업데이트 후 첫 실행에서 요약 청크를 다시 임베딩하므로 API 비용이 발생할 수 있습니다.
- 실제 외부 공급자의 유료 텍스트/이미지 생성과 실기기 클립보드 경로는 자동 검증 범위에 포함하지 않았습니다.
