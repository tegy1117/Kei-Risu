# Kei-Risu v2026.10.10

PocketRisu v1.14.0 (`64687d47e4d07de91a79a4053248e4d4eaf99ba2`)까지 통합했습니다. 기반 v1.9.0 이후 328개 커밋의 모델, 기능, 저장 및 UI 개선을 포함합니다.

## 업데이트

- 전체 모델 레지스트리와 신규 공급자/프로필: GPT-6, Claude Fable 5.1 및 Opus 5.5, Gemini 3.7/3.8 Flash, DeepSeek V4.1 Flash, GLM 5.3, Grok 4.7, Qwen 3.8, Square1 등.
- NovelAI Diffusion V5 이미지 모델과 모델별 Vibe Transfer 호환성 처리, Voyage Context 4 임베딩.
- 모델 바인딩 칸별 프리셋/레거시 모델 선택, 채팅별 장기 메모리 프리셋, 토글 기본값.
- 캐릭터 비활성화/복원 및 폴더 관리, 설정/선택창/모바일 UI 개선, 번역 부분 편집.
- 에셋 매니페스트와 플러그인 저장소 분리, 저장 충돌 및 복구 보호, 백업 다운로드/설정 전용 백업, 플러그인 API 개선.
- 긴 추론 요청 시간 초과, 다이나믹 에셋 조회 지연, 중지 후 생성 잠금 문제 수정.
- 포터블 및 Docker 배포에 서버 실행용 의존성만 포함.

## Kei-Risu 기능 보존 및 통합

- Agent 사전/사후 파이프라인, 부분 성공, 응답/표시 분리, 스와이프별 Agent 기록.
- MCP, 관리형 Tool App, 대화형 도구, 네트워크 프로필 및 공용 네트워크 프록시 제한.
- 도구별 공개 범위/스키마 호환성, 정규식 단계, 도구 상태/에셋/토글, 요청 추적.
- PocketRisu 백업 왕복 내보내기를 새 다운로드 API에 연결.
- 새 메모리/토글 기본값과 기존 기본 Agent 바인딩을 함께 유지.
- 캐릭터 비활성화/저장 충돌 이후 늦게 끝난 Agent가 다른 캐릭터에 결과를 쓰지 않도록 보호하고, 생성 정리는 해당 실행 ID에 한정.
- Kei-Risu 브랜딩, GitHub 업데이트 경로, 기존 저장 볼륨 이름 유지.

## 검증 및 호환성 참고

- 타입 검사, 프로덕션 빌드, 도움말 키 검사 및 클라이언트/서버/백업 호환성 테스트 수행.
- 기존 업스트림 백업 파일을 필요로 하는 5개 테스트는 외부 fixture가 없어 제외됩니다. 생성한 백업의 실제 서버 가져오기/내보내기와 Kei-Risu 사용자 필드는 별도로 검증합니다.
- 업스트림 v1.14 규칙에 따라 기존 전역 “레거시 모드 고정”은 해제됩니다. 필요하면 모델 바인딩 칸에서 레거시 모델을 다시 지정하십시오.
- 새 매니페스트/플러그인 저장 구조로 전환되므로 이전 서버 이미지로 되돌릴 때는 업데이트 전 저장 데이터 백업도 함께 복원해야 합니다.
- 실제 외부 공급자의 유료 모델/이미지 생성은 자동 검증에 포함하지 않습니다.
